# Contributing to Sitara MPU Open Source

Engineers can submit blogs through normal Git pull requests.

1. Create a branch.
2. Copy `docs/blog-template.md` to `_posts/YYYY-MM-DD-short-title.md`.
3. Fill in the front matter and write the article in Markdown.
4. Add approved images under `assets/images/blogs/`.
5. Open a Pull Request.
6. Obtain technical/public-release review.
7. Merge after approval; GitHub Pages publishes the site.

## Review checklist
- [ ] Technical review completed
- [ ] No confidential or restricted information
- [ ] Product/performance claims verified
- [ ] Links verified
- [ ] Images/diagrams approved
- [ ] Author attribution verified
