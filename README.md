# Sitara MPU Open Source - Community Connect

Welcome to the **Sitara MPU Open Source** community.

This repository powers the Sitara MPU open-source engineering portal:

https://texasinstruments.github.io/sitara-open-source-talks/

The portal brings together engineering knowledge from the Sitara MPU software
community, including technical blogs, conference talks, videos, projects,
and other resources that can help developers build with Sitara devices.
